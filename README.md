# Nordheide Stories

Menschen. Orte. Geschichten. Statische Website, läuft ohne Build direkt aus diesem Ordner (z. B. auf IONOS oder GitHub Pages).

- `index.html` Startseite, `geschichten.html` Übersicht, `geschichte-*.html` die Beiträge
- `site.css` / `site.js` Gestaltung und Verhalten für alle Seiten
- Beiträge im Magazin-Look: Bild als Cover, Vorspann, Initial, Zitat, Bildstrecke zum Wischen, Steckbrief, nächste Folge
